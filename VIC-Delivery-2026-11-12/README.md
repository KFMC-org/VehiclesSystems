# حزمة تسليم VIC

هذه حزمة إضافات نظام العربات VIC ومكوّن SmartDynamicFields، وليست نسخة من SmartFoundation وليست مشروعًا مستقلًا قابلًا للتشغيل.

ابدأ من `Documentation/README.md`، ثم راجع `DEPENDENCIES.md` و`INTEGRATION-GUIDE.md` قبل الدمج. لم يُنفّذ أي Commit أو Push أو أي أمر يغير قاعدة البيانات عند إنشاء الحزمة.
